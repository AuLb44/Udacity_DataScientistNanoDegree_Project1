# How Credit Shapes Economic Growth: Insights from World Bank Data

## Project Overview
This project explores the relationship between credit availability and GDP growth using World Bank economic indicators. The analysis follows the CRISP-DM process: data understanding, preparation, modeling, and evaluation.

## Motivation
Economic growth is influenced by multiple factors, including credit availability, inflation, and unemployment. Understanding these relationships can help policymakers make informed decisions.

## Business Questions
1. Which countries have the highest GDP growth?
2. How does credit availability correlate with GDP growth?
3. What is the relationship between inflation and unemployment?
4. Can we predict GDP growth based on credit and economic indicators?
